## Projects

### 1. [Transcriptomic Changes in Pancreatic Islets in Type 2 Diabetes](https://github.com/3o5k/GSE164416-islets-t2d)
RNA-seq analysis in R of laser-captured human islets from donors with type 2 diabetes and non-diabetic donors (GEO: GSE164416, n = 39), using DESeq2. Quality control identified exocrine contamination as the main source of variation (PC1, 49% of variance), and it was adjusted for in the model together with library batch. Includes apeglm shrinkage, GSEA with MSigDB Hallmark sets and sensitivity analyses. T2D islets showed lower oxidative phosphorylation and secretory gene programmes and higher inflammatory and extracellular-matrix signatures.

### 2. [Oxidative Stress Transcriptomics in Human Atherosclerotic Plaque](https://github.com/3o5k/oxidative-stress-atherosclerosis-transcriptomics)
Differential expression and gene-panel enrichment analysis of 223 public microarray samples (GEO: GSE21545, carotid plaque and matched PBMC). Age-adjusted models with FDR correction, Fisher's exact and rank-based enrichment tests, and a paired positive-control comparison. An earlier candidate dataset (GSE57691) was set aside after a batch confound was diagnosed.

### 3. [Antioxidant Gene Network Analysis](https://github.com/3o5k/antioxidant-gene-network-analysis)
Protein–protein interaction network of a 39-gene oxidative stress panel built from the STRING API, with hub identification by degree and betweenness centrality, community detection, and nodes annotated with expression changes from Project 2.

### 4. [Oxidative Stress Biomarker Analysis (MSc Thesis)](https://github.com/3o5k/oxidative-stress-atherosclerosis-analysis)
Statistical pipeline for my MSc thesis on N-acetylcysteine in a rat model: assumption testing, one-way ANOVA with Tukey HSD, correlation, regression and principal component analysis of five serum biomarkers across five experimental groups.
